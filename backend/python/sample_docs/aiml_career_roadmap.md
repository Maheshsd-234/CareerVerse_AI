# AI/ML Career Roadmap: From Student to Practitioner

## Why AI/ML in 2025?

Artificial Intelligence and Machine Learning have become the defining technologies of the decade. India is a major hub for AI talent, with demand growing 35–40% year-over-year across startups, MNCs, and research labs. The government's IndiaAI Mission aims to train 5 million AI practitioners by 2027.

## Who Is This Roadmap For?

- Class 12 students planning their degree.
- B.Tech students (any stream) wanting to pivot to AI/ML.
- Working professionals looking to transition.

## Phase 1: Strong Foundation (Class 12 / First Year B.Tech)

### Mathematics (Most Critical)

- **Linear Algebra:** Vectors, matrices, eigenvalues/eigenvectors. Watch 3Blue1Brown's "Essence of Linear Algebra" series.
- **Calculus:** Derivatives, partial derivatives, chain rule (used in backpropagation).
- **Probability & Statistics:** Probability distributions, Bayes' theorem, expectation, variance.
- **Recommended book:** "Mathematics for Machine Learning" by Deisenroth, Faisal, Ong (free PDF available).

### Programming

- Learn **Python** first (most ML libraries are Python-based).
- Core: loops, functions, OOP, file I/O.
- Libraries: NumPy, Pandas, Matplotlib.
- Practice: HackerRank Python 30-day challenge, then Kaggle intro courses (free).

## Phase 2: Core ML Skills (Year 2–3 B.Tech / 6 months self-study)

### Machine Learning Fundamentals

- Andrew Ng's ML Specialization on Coursera (gold standard for beginners).
- Topics: Linear regression, logistic regression, decision trees, SVM, k-means, neural networks basics.
- Apply with scikit-learn on real datasets (Kaggle beginner competitions: Titanic, House Prices).

### Deep Learning

- fast.ai Practical Deep Learning for Coders (free, hands-on).
- PyTorch (preferred for research) or TensorFlow/Keras (industry standard).
- Projects: Image classification, sentiment analysis, simple chatbot.

### Data Engineering

- SQL (essential — most ML teams work with databases).
- Pandas, data cleaning, feature engineering.
- Basic data pipeline: fetch → clean → transform → model → evaluate.

## Phase 3: Specialization (Year 4 / 1+ year experience)

### Choose One Vertical

| Specialization | Skills | Hiring Companies |
|----------------|--------|-----------------|
| NLP / LLMs | HuggingFace, LangChain, RAG, fine-tuning | Sarvam, Krutrim, Microsoft, OpenAI India |
| Computer Vision | OpenCV, YOLO, Detectron2 | Ola, Navi, Bharat Forge |
| MLOps | MLflow, Kubeflow, DVC, Airflow | All large product companies |
| Recommender Systems | Collaborative Filtering, Matrix Factorization | Flipkart, Amazon, Netflix |
| AI for Healthcare/Fintech | Domain data + ML | Niramai, Artivatic, BankBazaar |

### LLM & RAG (Hottest in 2025)

Retrieval-Augmented Generation (RAG) is the dominant architecture for enterprise AI products:
- Learn: LangChain or LlamaIndex, vector databases (Qdrant, Pinecone, Weaviate).
- Build: A document QA system, then a multi-document RAG pipeline.
- Highly employable: RAG engineers command ₹20–60 LPA even at 2–3 years experience.

## Portfolio Building

A strong GitHub portfolio beats a mediocre degree from a top college:

1. **Kaggle:** Reach Expert or Master tier. Shows competition and ML fundamentals.
2. **GitHub Projects:** 3–5 well-documented projects. Include a RAG chatbot, an image classifier, and a data analysis project.
3. **Kaggle Notebooks:** Publish tutorials on well-known datasets.
4. **Blog:** Medium or Substack — writing about ML concepts you've learned signals depth.

## Job Hunting

- **Entry level (Fresher):** Apply to ML internships in Year 3. Convert to full-time.
- **Platforms:** LinkedIn, AngelList India, Cutshort, Instahyre, iimjobs.
- **Fresher CTC:** ₹8–20 LPA at product/startup; ₹3.5–6 LPA at service companies.
- **Key interviews:** DSA round (LeetCode), ML concepts round, practical case study.

## Certifications That Help

- **Google Professional ML Engineer** (GCP).
- **AWS Certified ML Specialty**.
- **DeepLearning.AI Specializations** on Coursera.
- **Kaggle Certificates** (free, respected in India).
